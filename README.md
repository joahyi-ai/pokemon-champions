# Pokemon Champions Hub

[![Live Site](https://img.shields.io/badge/Live_Site-pokemonchampions.online-ee1515?style=for-the-badge)](https://pokemonchampions.online/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg?style=for-the-badge)](LICENSE)

The ultimate guide and resource hub for **Pokemon Champions** — the free-to-play, battle-focused Pokemon game by The Pokemon Works, available on Nintendo Switch, Switch 2, iOS and Android.

**[Visit the live site](https://pokemonchampions.online/)**

## What's Inside

- **Game Overview** — What is Pokemon Champions, release date, supported platforms
- **Battle Modes** — Breakdown of all three competitive battle modes
- **Mega Stones Guide** — Full list of 57 Mega Stones, how to obtain them, and Legends Z-A transfer exclusives
- **Launch Bug Tracker** — Known issues, server status, and workarounds for launch-week problems
- **Top YouTube Coverage** — Curated videos from the community's best creators
- **Pricing Breakdown** — Free-to-start model, membership, Starter Pack, and Battle Pass details
- **FAQ** — Answers to the most common questions about the game

## Tech Stack

- Static HTML / CSS / JavaScript (single page)
- Hosted on [Cloudflare Workers](https://workers.cloudflare.com/)
- Google Analytics (gtag.js)
- Structured Data (Schema.org JSON-LD) for SEO
- Fully responsive design with scroll-triggered animations

## Run Locally

```bash
git clone https://github.com/joahyi-ai/pokemon-champions.git
cd pokemon-champions
# Open index.html in your browser, or use any static server:
npx serve .
```
